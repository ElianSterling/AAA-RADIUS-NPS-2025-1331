# Evidencias visuales del laboratorio

[← Regresar al README principal](../README.md) · [Catálogo de las 21 capturas](../docs/09-evidencias-visuales.md)

La carpeta contiene **21 imágenes PNG auténticas**, seleccionadas de un conjunto original de 43 capturas. Se publican sin alterar sus resultados técnicos y están agrupadas por área:

| Directorio | Evidencia |
|:--|:--|
| `01-topologia/` | Diagrama visual del proyecto GNS3 |
| `02-servidor-ad/` | Windows Server, AD DS y grupos |
| `03-nps-clientes-politicas/` | Clientes RADIUS, Network Policies y Cisco-AV-Pair |
| `04-conectividad/` | Interfaz R1, VLAN 13 y firewall NPS |
| `05-ssh-aaa/` | SSH y privilegios de sesión |
| `06-auditoria-nps/` | Eventos 6272 y configuración de accounting |

**Importante:** algunas capturas reflejan etapas del 21–27 de octubre de 2026 y no constituyen, por sí solas, prueba de los cambios realizados el 29 de octubre. Los resultados finales se documentan en [Pruebas y evidencias](../docs/05-pruebas-y-evidencias.md).

No publicar capturas con contraseñas, claves compartidas RADIUS, hashes o certificados privados. El respaldo `NPS-Backup.xml` no pertenece a este directorio.
