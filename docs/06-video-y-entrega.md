## Grabación

**El estudiante confirmó que el video demostrativo ya está grabado.** La URL de YouTube se incorporará en la primera sección del [README](../README.md) en cuanto se comparta el enlace. No se declara duración ni cumplimiento audiovisual como verificados hasta poder revisar el archivo o su publicación.

## Requisitos de la actividad

| Criterio | Consideración |
|:--|:--|
| Duración | **Máximo 10 minutos** |
| Presentador | Debe verse el rostro del estudiante y escucharse su voz |
| Identificación temporal | Fecha y hora visibles durante la demostración según rúbrica documentada |
| Contenido | Topología, AD DS, NPS, SSH, privilegios, consola/AUX y logs de accounting |
| Publicación | Video propio publicado en YouTube |
| Acceso | El enlace debe abrir correctamente para el docente |
| Enlace destacado | Colocar la URL al inicio del README |
| Archivo TXT | Incluir enlace al repositorio y enlace al video, con la nomenclatura exacta solicitada |

## Orden de demostración sugerido

| Tiempo de referencia | Prueba |
|:--|:--|
| 0:00–0:35 | Identificación del estudiante y alcance |
| 0:35–1:10 | Topología GNS3 |
| 1:10–2:05 | Grupos y usuarios AD DS |
| 2:05–3:00 | Clientes y políticas RADIUS de NPS |
| 3:00–4:30 | SSH y niveles 0/5/10 en R1 |
| 4:30–6:00 | SSH y comprobación de SW1 |
| 6:00–7:00 | Acceso AAA local a consola y configuración AUX |
| 7:00–8:40 | 6272/6273 y START/STOP en NPS |
| 8:40–9:20 | Configuraciones saneadas y conclusión |

Este cronograma es una **guía de contenido**, no una aseveración de que la grabación efectivamente tenga esa duración exacta.

## Enlaces de entrega

- **Repositorio:** https://github.com/ElianSterling/AAA-RADIUS-NPS-2025-1331
- **Video:** se incorporará únicamente al recibir la URL real publicada.

La rúbrica registra el patrón `<Nombre>_<Matrícula>_<P#>.txt` para el archivo de entrega. No se inventará el valor `P#`; debe coincidir con la identificación oficial de la asignación.

## Verificación final antes de entregar

1. Abrir el enlace del video en un navegador sin sesión privada.
2. Confirmar que el audio, la cámara, la fecha y los resultados son legibles.
3. Comprobar que el video no divulga contraseñas ni claves compartidas.
4. Agregar el enlace real al README y al TXT.
5. Verificar que GitHub y YouTube sean accesibles para el profesor.
